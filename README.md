# \# Student Study Planner

# 

# A desktop application designed to help students organize their academic tasks, manage deadlines, set weekly study goals, and track their study progress in one place.

# 

# \## About the Project

# 

# Student Study Planner was developed to make academic planning simpler and more organized. Instead of keeping track of assignments, exams, and study sessions separately, students can manage their academic tasks through a single desktop application.

# 

# The application allows users to create and manage study tasks, prioritize upcoming work, monitor completion progress, and set weekly study-hour goals.

# 

# \## Features

# 

# \* Add, edit, and delete study tasks

# \* Organize tasks by subject and type

# \* Set due dates for academic tasks

# \* Assign High, Medium, or Low priority

# \* Add estimated study time in hours and minutes

# \* Mark tasks as completed

# \* Filter and view tasks based on different criteria

# \* Track study progress over a selected period

# \* Set and monitor weekly study-hour goals

# \* View subject-based monthly summaries

# \* Receive visual feedback for completed and upcoming tasks

# \* Save tasks locally so they remain available after restarting the application

# 

# \## Technologies Used

# 

# \* C#

# \* Windows Forms (WinForms)

# \* .NET Framework 4.7.2

# \* Visual Studio

# \* Git

# \* GitHub

# \* CSV and text-file based local storage

# 

# \## Project Structure

# 

# The application is divided into multiple components, each responsible for a specific part of the study planning experience.

# 

# \* `StudyTask.cs` — Defines the study task data model.

# \* `TaskManager.cs` — Manages the application's collection of study tasks.

# \* `FileStorage.cs` — Handles saving and loading application data.

# \* `AddTask.cs` — Allows users to create new study tasks.

# \* `EditTask.cs` — Handles modifications to existing tasks.

# \* `TrackProgress.cs` — Calculates and displays study progress.

# \* `Summary.cs` — Provides subject-based study summaries.

# \* `WeeklyGoalForm.cs` — Allows students to set and track weekly study goals.

# 

# \## How It Works

# 

# Students create tasks by entering information such as the task title, subject, type, due date, priority, and estimated study duration.

# 

# The planner stores task information locally and allows students to update their tasks as they progress. Completed tasks contribute to progress tracking, while weekly goals help students monitor their planned study hours.

# 

# The application also provides filtering and summary features to make it easier to understand upcoming academic responsibilities.
